# お給料ノート

スタッフの勤務記録から、月間・年間給与、CSV給与明細、画像給与明細を作成するシンプルなブラウザアプリです。

## 起動方法

`index.html` をダブルクリックしてブラウザで開いてください。より安定して利用する場合は、このフォルダで次を実行します。

```bash
python3 -m http.server 4173
```

その後、ブラウザで `http://localhost:4173` を開きます。

## 計算ルール

- 通常時給：1,160円
- 研修時給：1,000円
- 開始から終了までの時間から休憩時間を控除
- 控除後の実働時間を15分単位で切り捨て
- 交通費：なし／500円／1,000円／2,000円／3,000円
- 仕事中止時：勤務時間を計上せず、補填金3,000円を加算
- 月次調整額：給与明細画面で月ごとに入力。正の数で加算、負の数で減算

## データについて

入力したスタッフと勤務記録はブラウザのローカルストレージに自動保存されます。同じ端末・同じブラウザで利用してください。ブラウザの閲覧データを消去すると記録も消えるため、月ごとにCSVを保存してバックアップすることをおすすめします。
